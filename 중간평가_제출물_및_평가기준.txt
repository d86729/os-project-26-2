3. 중간평가 제출물
중간평가는 조 제출물 4종과 개인 제출물 2종으로 구성됨. 발표는 없으며, 모든 평가는 서면 제출물로 이루어짐. 서면 제출물에 대한 조별 면담 진행 예정.

	① 논문 초안(앞부분)
기말에 제출할 논문의 앞부분을 실제 논문 양식으로 작성. 중간평가 이후 그대로 이어서 완성하게 되므로 별도 계획서를 만들 필요가 없음.
* 제목, 초록(안): 초록은 중간 시점의 가안으로 작성
* 서론: 연구 배경과 필요성, 해결하려는 문제, 연구 질문, 예상 기여를 포함
* 관련 연구: 조원들의 개인 요약(⑤)을 종합해 기존 연구의 흐름과 본 연구의 차별점을 서술
* 제안 방법 개요: 기존 방법의 한계와 이를 보완할 제안 기법의 아이디어를 설명
* 실험 설계: 사용할 데이터와 출처, 비교 기준(기준선), 평가 지표, 실험 조건(조원별 담당)을 명시
* 참고문헌: 학회 양식에 맞춰 정리
* ② 기준선 재현 결과와 코드
비교 대상이 되는 기존 방법(기준선)이 실제 데이터에서 동작하는 것을 보여야 함. 결과 보고에는 데이터 로딩 과정, 기준선 실행 결과(표 또는 그래프), 발견한 문제점을 포함함.
* 노트북은 처음부터 끝까지 오류 없이 실행되어야 함.
* 각 코드 셀 위에 담당 조원 이름을 표시함.
* 기준선 구축 자체가 어려운 주제(붙임 1의 난이도 상 주제)는 기준선의 일부 동작 확인까지를 인정하며, 평가 시 주제 난이도를 감안함.
* ③ 역할 분담표
조원별 담당 실험 조건, 담당 논문 절, 관련 연구 조사 범위를 표로 정리함.
④ 향후 연구 계획
최종 논문 제출일까지 주차별 계획과 예상되는 어려움, 그 대응 방안을 작성함.
⑤ 관련 연구 개인 요약
조원 각자가 본 연구와 관련된 논문 2~3편을 읽고 개인 이름으로 요약. 조원 간 논문이 겹치지 않도록 사전에 분배. 논문마다 다음을 포함해야 함.
* 서지 정보(저자, 제목, 학회·학술지, 연도)
* 연구 문제, 사용 방법, 주요 결과(본인의 말로 요약)
* 본 연구와의 관계: 무엇을 참고하고, 무엇이 다른가
4. 평가 기준과 배점

6. 유의사항
데이터와 보안
* 연구에는 공개 데이터 또는 공개 규격을 바탕으로 생성한 합성 데이터만 사용함. 군 내부 자료나 비공개 자료는 사용할 수 없음.
* 모든 데이터는 출처(기관명, 주소, 접근 일자)를 논문과 노트북에 명시함.
연구윤리
* 다른 사람의 문장, 그림, 코드를 사용할 때는 반드시 출처를 밝힘. 출처 없는 인용은 표절로 간주.
* 실험 결과를 조작하거나 실행하지 않은 결과를 기재하면 해당 제출물 전체를 0점 처리함.
* 다른 조와 코드나 문서를 공유 불가.토론은 자유롭게 하되, 결과물은 각 조가 직접 작성.
생성형 AI 사용
* 생성형 AI는 개념 이해, 문법 교정, 디버깅 보조 용도로 사용할 수 있음.
* AI가 만든 코드나 문장은 본인이 이해하고 설명할 수 있어야 하며, 개별 확인 면담에서 설명하지 못하면 해당 부분은 본인 기여로 인정하지 않음.
* AI가 제시한 참고문헌은 실제로 존재하는지 반드시 직접 확인함. 존재하지 않는 문헌을 인용하면 연구윤리 위반으로 처리함.
