# 쉬운 전략 코드와 공통 평가

1~3번은 `results/agent-study/2026-11-22/agent-{1,2,3}/`의 기존 실행 파일을 쉬운 버전으로 바꿨다. AI 보조 수정이며, 각 담당자의 직접 작성·이해 범위와 구별한다.

4번 `agent4_exhaustive.py`는 팀원과 같은 텍스트 입력을 받아 가능한 방호안 전부를 탐색하고 번호를 출력하는 작은 문제 설명용 파일이다. 단순화를 위해 점수 공식을 복사하지 않고 `protection.evaluation.Evaluator`를 직접 호출한다. 제출 답안의 공식 채점과 기존 완전탐색도 같은 Evaluator를 사용한다. 참조용 탐색은 유리수 인증을 요구한다. 이 설명용 파일은 기존 장시간 인증기와 운영 기록을 대체하지 않는다.

공통 평가기는 네트워크의 연결 쌍 수를 먼저 비교하고, 동점이면 전체 데이터 전달률을 비교한다. 최적 방호안이 인증된 네 개의 작은 문제에서 설명용 완전탐색의 점수와 방호안이 저장된 참조와 일치했다. 실행 시간과 메모리 제한은 사용하는 실행 환경에서 별도로 적용해야 한다.
