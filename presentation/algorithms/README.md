# 발표용 전략과 텍스트 파일 시연

제출 노트북에는 김대건의 차수/비용 기준선, 신동윤의 수요 경로 전략, 진명호의 전수 검사를 넣었다. 모든 전략은 공통 텍스트 문제를 표준 입력으로 받고 선택한 선 번호를 표준 출력으로 내보낸다.

`agent2_team.py`는 신동윤의 `solve` 함수에 텍스트 입력과 출력을 연결한 코드다. `agent4_team.py`는 진명호의 전수 검사 반복문에 같은 입력과 출력을 연결하고 공통 `Evaluator`를 사용한다. 4번의 일반 평가 시연은 별도의 엄밀한 유리수 인증을 대신하지 않는다.

`generate_text.py`는 문제 생성 시드를 명령행 인자로 받아 문제를 표준 출력으로 만든다. `read_text.py`와 `grade_text.py`는 생성된 문제와 답안 파일을 공통 평가기로 채점하기 위한 코드다. 노트북에서는 각각 `문제생성.py`, `문제읽기.py`, `채점.py`로 생성한다.
