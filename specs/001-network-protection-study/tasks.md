# Tasks: 통신망 방호 연구 및 전략 중립적 일괄 채점

**Input**: 동일 디렉터리의 spec.md, plan.md, research.md, data-model.md, quickstart.md 및 코딩 테스트의 표준 입출력 계약.
**Prerequisites**: U-001~003 사용자 확정. 프로젝트 헌법과 extension hooks는 현재 없다.
**Status**: 공통 평가와 공개 문제은행 인증을 완료했다. 아래 구현 체크는 최초 검증 이력을 보존한다. 클래스·4GB RSS 작업은 이전 실행기의 이력이며 현행 제출 채점 작업과 환경별 재검증은 [코딩 테스트 작업 목록](../002-coding-test/tasks.md)에 있다. T054~T056/T060은 본 실험 운영 입력·승인·실제 팀원 제출을 기다린다.
**Tests**: spec.md FR-025 및 각 Story의 수락 조건에서 명시적으로 요구한다. 시험을 먼저 작성하고 예상 실패를 확인한 후 구현하며, 단순 import 실패만으로 동작 검증을 대체하지 않는다.
**Organization**: 공통 기반 → US1 공통 평가 → US2 정확 탐색 → US3 제출 계약·한도 → US4 결과 통합 → 교차 검수. 구현 책임은 김대건 범위이며 팀원 세 전략의 본문은 제외한다.

## Format: `[ID] [P?] [Story] Description`

모든 작업은 미완료 체크박스로 시작한다. [P]는 같은 시험 작성 묶음에서 서로 다른 파일을 병렬 작성할 수 있다는 뜻이며, 선행 기반 작업을 생략해도 된다는 뜻이 아니다. 공식 실험과 자원·시간 측정 시험은 단일 장비에서 직렬 실행한다.

## Path Conventions

경로는 프로젝트 루트 기준이다. 공통 모듈은 protection/, 시험은 tests/에 있다. 팀원 소스는 웹 제출 시 SQLite에 저장한다. 아래 완료 작업의 클래스·골격 파일 참조는 이전 구현 이력이다. 아래 시험 파일명과 결과 파일명은 구현 작업의 목표 경로이며 현재 존재한다는 주장이 아니다. 별도 contracts/ 또는 팀원 인계 문서를 만들지 않는다.

## Implementation Strategy

1. US1: 공통 평가와 수치 정책 확립.
